## Overview

AS-Portfolio is a responsive, production-ready portfolio application built with React and Vite. It combines elegant UI design, reusable component architecture, analytics-driven sections, and AI-inspired portfolio insights to present a compelling professional brand online.

## Why This Project Matters

This portfolio is more than a personal website. It demonstrates how modern frontend engineering, interactive storytelling, and AI-assisted analytics can work together to build a polished digital presence for students, developers, and professionals seeking opportunities in tech and innovation.

## Highlights

- Professional personal branding and storytelling
- Interactive project and skills showcase
- AI-enhanced analytics and recommendations
- Responsive layout optimized for desktop and mobile
- Automated testing and production build validation

## Getting Started

### Prerequisites
- Node.js 18 or higher
- npm 9 or higher

### Installation

```bash
npm install
```

### Development Server

```bash
npm run dev
```

### Production Build

```bash
npm run build
```

### Testing

```bash
npm test -- --run
```

## Deployment

This project is configured for GitHub Pages deployment through GitHub Actions.

Steps to enable deployment:
1. Open the repository Settings.
2. Navigate to Pages.
3. Set Build and deployment source to GitHub Actions.
4. Push changes to `main` to trigger the workflow automatically.

The workflow in `.github/workflows/deploy.yml` builds the site and publishes the `dist/` output to GitHub Pages.
